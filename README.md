# Site Comunidade Gileade

Modelo pronto para publicar gratuitamente no GitHub Pages.

## Arquivos
- `index.html`
- `style.css`
- `script.js`
- `assets/logo-gileade.png`

## Já incluído
- Avisos da Semana como conteúdo principal
- Aba Novo Templo
- Botão Configurações
- Opção Suporte
- Sobre
- Privacidade
- YouTube oficial
- Instagram oficial
- Botão para copiar PIX
- Layout responsivo

## Links adicionados
- YouTube: https://www.youtube.com/@ComunidadeGileade
- Instagram: https://www.instagram.com/comunidadegileade/

## Antes de publicar
Edite no `index.html`:
1. `SEU-PIX-AQUI`
2. `contato@comunidadegileade.com`
3. Endereço da igreja
4. Datas e horários dos avisos

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos.
3. Vá em Settings > Pages.
4. Em Source/Build and deployment escolha Deploy from a branch.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a publicação.
